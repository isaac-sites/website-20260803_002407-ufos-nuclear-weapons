## Introduction

[Hanford]({{ 'hanford/' | relative_url }})’s UFO reports are best understood as part of a wider atomic-era pattern rather than as an isolated set of incidents. The key comparison is not simply that “UFOs appeared near nuclear sites”, but that reports around Hanford, Los Alamos, Oak Ridge and later atomic facilities emerged during a period when nuclear technology, military secrecy, radar development and Cold War surveillance were rapidly changing how unusual aerial events were interpreted. Hanford occupies a special place in this timeline because it was one of the first locations where alleged unexplained aerial activity became linked with the production of [nuclear weapons]({{ 'nuclear-weapons/' | relative_url }}) materials.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://home.nps.gov/mapr/learn/manhattan-project.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: home.nps.gov">[National Park Service]</a><span class="citation-popover" role="note"><span class="citation-popover-source">home.nps.gov</span><span class="citation-popover-title">National Park Service Manhattan Project</span><span class="citation-popover-snippet">National Park ServiceManhattan Project - Manhattan Project National Historical Park (U.S. National Park Service)April 17, 2025...</span><span class="citation-popover-meta">Published: April 17, 2025</span></span></span>

## Early atomic-era sightings

### Hanford and the first nuclear-site narratives

Hanford became significant because of its role in the Manhattan Project. The site in Washington state produced plutonium on an industrial scale, supplying material for the Trinity test and the Nagasaki weapon. Its isolation, security restrictions and connection to a new class of military technology made it a natural focus for later stories about unexplained aerial activity.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://home.nps.gov/mapr/learn/manhattan-project.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: home.nps.gov">[National Park Service]</a><span class="citation-popover" role="note"><span class="citation-popover-source">home.nps.gov</span><span class="citation-popover-title">National Park Service Manhattan Project</span><span class="citation-popover-snippet">National Park ServiceManhattan Project - Manhattan Project National Historical Park (U.S. National Park Service)April 17, 2025...</span><span class="citation-popover-meta">Published: April 17, 2025</span></span></span>

The most famous Hanford account concerns an alleged 1945 incident in which an unidentified object was reportedly detected above the facility, followed by an attempted interception by Navy aircraft. Later accounts describe radar detection, multiple pilots attempting to approach the object, and a target that remained beyond interception range. However, the surviving documentation is uneven: the case is largely preserved through later recollections and UFO research publications rather than a complete publicly available wartime investigation file.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ufologie.patrickgross.org/acufo/1945-07-00-hanford.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufologie.patrickgross.org">[Ufologie]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufologie.patrickgross.org</span><span class="citation-popover-snippet">UFOs at close sight: ACUFO catalog - Case of the Hanford nuclear plant, Washington, USA, in July 1945July 2, 2024...</span><span class="citation-popover-meta">Published: July 2, 2024</span></span></span>

This makes Hanford different from some later cases. The story gained importance because of its timing — occurring near the end of the Manhattan Project and before the first nuclear test — but the evidential foundation is more dependent on retrospective testimony than on a large archive of official records. The distinction matters because a report of an unexplained event is not the same as confirmation of what caused it.

### The wider atomic setting

Hanford was one part of a much larger network of secret nuclear facilities. Oak Ridge, Tennessee, handled uranium enrichment and operated early plutonium-related research facilities, while Los Alamos, New Mexico, designed the weapons themselves. These sites formed a highly classified system in which unusual observations could easily become connected with fears of espionage, experimental technology or unknown aircraft.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nps.gov/articles/000/manhattan-project-science-at-oak-ridge.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nps.gov">[National Park Service]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nps.gov</span><span class="citation-popover-snippet">National Park ServiceManhattan Project Science at Oak Ridge (U.S. National Park Service)April 4, 2023...</span><span class="citation-popover-meta">Published: April 4, 2023</span></span></span>

The broader UFO reporting boom also developed during this period. After widely publicised sightings in 1947, the US Air Force created formal investigation programmes, eventually leading to [Project Blue Book]({{ 'project-blue-book/' | relative_url }}), which collected thousands of reports between the early Cold War period and 1969. Nuclear locations attracted particular attention because aerial security around them was considered strategically important.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://en.wikipedia.org/wiki/Project_Blue_Book" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: Wikipedia">[Wikipedia]</a><span class="citation-popover" role="note"><span class="citation-popover-source">Wikipedia</span><span class="citation-popover-title">Project Blue Book</span><span class="citation-popover-snippet">Project Blue Book</span></span></span>

## Similar nuclear site reports

### Oak Ridge: radar, witnesses and security concerns

Oak Ridge provides one of the closest comparisons with Hanford because it was another Manhattan Project location associated with nuclear production. Reports from 1950 described [unidentified objects]({{ 'unidentified-objects/' | relative_url }}) over the Oak Ridge installation, including accounts involving radar information and witness statements collected by authorities. These reports appeared during a period when the United States was increasingly concerned about Soviet espionage and technological competition after the Soviet atomic bomb test in 1949.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nicap.org/docs_oakridge/fbi501021doc1.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nicap.org">[Nicap]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nicap.org</span><span class="citation-popover-snippet">UFOS at close sight: FOIA declassified documents, UFOs over Oak Ridge nuclear plant, 1950October 21, 1950...</span><span class="citation-popover-meta">Published: October 21, 1950</span></span></span>

The similarity with Hanford is clear: both cases involved restricted atomic facilities, military attention and questions about possible threats. The difference is that Oak Ridge reports occurred after the establishment of a broader [UFO investigation]({{ 'ufo-case-investigation/' | relative_url }}) culture, when agencies were already collecting and categorising sightings. Hanford’s earliest reports belong more directly to the transition from wartime secrecy into the early UFO era.

### Los Alamos and the association between UFOs and nuclear research

Los Alamos became another important location in atomic-era UFO narratives because it was the centre of bomb design and later nuclear weapons research. Reports associated with the New Mexico region often became connected with the idea that unidentified objects were appearing near places involved in nuclear development. However, the historical record includes a mixture of documented observations, later interpretations and popular retellings, making individual cases difficult to assess consistently.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.osti.gov/opennet/manhattan-project-history/Events/1942-1945/establishing_los_alamos.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: osti.gov">[OSTI]</a><span class="citation-popover" role="note"><span class="citation-popover-source">osti.gov</span><span class="citation-popover-title">establishing los alamos</span><span class="citation-popover-snippet">Manhattan Project: Establishing Los Alamos, 1942-1943...</span></span></span>

The Los Alamos comparison highlights a broader pattern: nuclear facilities were not only technologically important but symbolically important. They represented humanity’s first large-scale use of nuclear science, so unusual events near them attracted greater attention than similar reports elsewhere.

## Differences between cases

### Evidence quality changed after Hanford

The biggest difference between Hanford and later atomic-era reports is the amount and type of documentation available. The 1945 Hanford account is notable mainly because of its connection to the birth of the nuclear age, but much of the commonly repeated narrative comes from later interviews and secondary investigations.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ufologie.patrickgross.org/acufo/1945-07-00-hanford.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufologie.patrickgross.org">[Ufologie]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufologie.patrickgross.org</span><span class="citation-popover-snippet">UFOs at close sight: ACUFO catalog - Case of the Hanford nuclear plant, Washington, USA, in July 1945July 2, 2024...</span><span class="citation-popover-meta">Published: July 2, 2024</span></span></span>

### The meaning of “nuclear connection” shifted over time

Early Hanford stories focused on the extraordinary secrecy surrounding the first atomic weapons programme. The central question was whether an unknown object could have been connected with a revolutionary military project that few people understood.

Later cases increasingly reflected Cold War anxieties. Reports near nuclear facilities could be interpreted through concerns about Soviet reconnaissance, advanced aircraft, radar limitations or accidental misidentification. The same location type — a nuclear site — produced different interpretations depending on the political and technological climate.

    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
