## Introduction

AARO (the All-domain Anomaly Resolution Office) has found that many unresolved UAP cases remain open not because investigators have confirmed unusual technology, but because the available evidence is often too incomplete to determine what happened. The central problem is a data gap: a report may contain a video, radar indication, or witness account, yet lack the measurements needed to establish an object’s distance, speed, identity, or physical characteristics. AARO’s investigations therefore treat unresolved cases as an evidence-quality problem as much as an identification problem.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/UAP-Cases/Official-UAP-Imagery/4/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-title">UAP Imagery</span><span class="citation-popover-snippet">AARO UAP Imagery...</span></span></span>

This issue is especially important for UAP reports connected to sensitive military environments, including areas associated with [nuclear security]({{ 'security-concerns-0719dd/' | relative_url }}). In such settings, sensors are usually designed for operational missions rather than scientific measurement. They may detect something unusual without recording the full set of information needed for later analysis. ## How AARO evaluates incomplete reports

AARO’s approach separates two questions that are often confused: whether an event was genuinely observed, and whether the available evidence is sufficient to identify it. A case can involve a real object or signal while still remaining unresolved because the evidence does not support a reliable conclusion.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/UAP-Cases/Official-UAP-Imagery/4/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-title">UAP Imagery</span><span class="citation-popover-snippet">AARO UAP Imagery...</span></span></span>

The office reviews information from multiple possible sources, including infrared imagery, radar-related data, operational reports, and other intelligence records. However, many reports arrive with only fragments of the original observation. A short video clip, for example, may show an apparent object but omit the sensor settings, range information, aircraft position, environmental conditions, or additional sensor feeds needed to interpret it correctly.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/UAP-Cases/Official-UAP-Imagery/4/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-title">UAP Imagery</span><span class="citation-popover-snippet">AARO UAP Imagery...</span></span></span>

The difference between a resolved and unresolved case often comes down to whether investigators can match observations against known explanations. AARO has published cases where additional analysis identified ordinary explanations such as balloons or birds, but it has also released unresolved cases where the remaining information was insufficient to determine whether an apparent object represented a physical source, a thermal effect, or a sensor-related issue.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/UAP-Cases/Official-UAP-Imagery/4/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-title">UAP Imagery</span><span class="citation-popover-snippet">AARO UAP Imagery...</span></span></span>

For UAP investigations, “unresolved” therefore does not mean “proven extraordinary”. It means the evidence has not reached the threshold required for a confident attribution. This distinction is central to AARO’s framework because a weak dataset can prevent both confirmation and elimination of possible explanations.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.reuters.com/technology/space/pentagon-ufo-report-says-most-sightings-ordinary-objects-phenomena-2024-03-08/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: reuters.com">[Reuters]</a><span class="citation-popover" role="note"><span class="citation-popover-source">reuters.com</span><span class="citation-popover-snippet">Most sightings were identified as ordinary objects or phenomena. The All-domain Anomaly Resolution Office (AARO) released this conclusion...</span></span></span>

## Common missing evidence problems

Many unresolved [AARO cases]({{ 'aaro-cases/' | relative_url }}) share recurring evidence limitations. These problems affect how investigators interpret military sensor recordings and explain why some cases remain open.

**Missing range and position data**

A recording alone may not reveal how far away an object was or how it moved through space. Without accurate distance measurements, apparent speed or unusual motion can be misleading. A small nearby object and a larger distant object can create very different interpretations when only a single camera view is available.

**Incomplete sensor metadata**

[Sensor data]({{ 'sensor-data/' | relative_url }}) is most useful when analysts know exactly how the system was operating. Missing information about camera modes, calibration, tracking settings, geographic position, altitude, weather, and timing can prevent analysts from reproducing the observation. NASA’s independent UAP study highlighted the lack of high-quality, standardised observations as a major barrier to scientific assessment.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/uap/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[NASA Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science UAP</span><span class="citation-popover-snippet">NASA ScienceUAP - NASA ScienceFebruary 23, 2026...</span><span class="citation-popover-meta">Published: February 23, 2026</span></span></span>

**Single-source observations**

A major weakness in many UAP reports is dependence on one type of evidence. An infrared image may show a heat signature, but without radar confirmation or other measurements it may be difficult to determine whether the signal represents an object, a reflection, an atmospheric effect, or a sensor artefact. AARO has specifically described unresolved imagery where available information was insufficient to determine the source of an apparent thermal signature.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/UAP-Cases/Official-UAP-Imagery/4/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-title">UAP Imagery</span><span class="citation-popover-snippet">AARO UAP Imagery...</span></span></span>

**Lost opportunities for real-time collection**

Some cases cannot be solved because investigators receive the report after the event has ended. A sensor team cannot return to the scene and collect additional measurements. This makes early data capture important: synchronised radar, optical, infrared, and environmental measurements provide a much stronger foundation than a single recording recovered later. NASA’s recommendations similarly focused on improving future data collection rather than relying only on historical reports.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/uap/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[NASA Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science UAP</span><span class="citation-popover-snippet">NASA ScienceUAP - NASA ScienceFebruary 23, 2026...</span><span class="citation-popover-meta">Published: February 23, 2026</span></span></span>

## Why some military videos remain unresolved

Military infrared videos are among the most discussed UAP evidence because they appear to provide direct recordings of unusual objects. However, infrared systems are specialised tools, not complete scientific observation platforms. They measure infrared radiation and are affected by factors including sensor configuration, atmospheric conditions, perspective, and tracking behaviour.

AARO’s public imagery archive illustrates this challenge. Some released cases remain unresolved because analysts can confirm that a sensor captured an apparent phenomenon but cannot determine its exact cause. In several examples, AARO notes that available data is insufficient to evaluate performance characteristics or establish whether the observed signature comes from a physical object or another source.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/UAP-Cases/Official-UAP-Imagery/4/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-title">UAP Imagery</span><span class="citation-popover-snippet">AARO UAP Imagery...</span></span></span>

This creates an important analytical limitation: a video can demonstrate that something appeared in a sensor’s field of view without proving what the object was or what capabilities it possessed. The missing information is often not the image itself, but the surrounding measurement context needed to interpret it.

## What better data could reveal

Improving UAP investigations depends less on collecting more ambiguous footage and more on collecting better-quality measurements. A stronger dataset would allow analysts to test competing explanations rather than simply classify an event as unknown.

Useful improvements include:


<div class="content-enhancement content-enhancement--metric" markdown="1">

* **Multi-sensor recording:** Combining radar, infrared, optical cameras, and other measurements can show whether different systems are observing the same physical event.
* **Precise timing and location data:** Accurate timestamps and positions help reconstruct trajectories and compare observations with known objects.
* **Sensor calibration records:** Knowing how instruments were configured allows analysts to distinguish real phenomena from equipment effects.
* **Consistent reporting procedures:** Standardised collection methods increase the scientific value of future cases.

</div>

NASA’s independent study reached a similar conclusion, stating that the limited number of high-quality UAP observations prevents firm scientific conclusions and recommending improved methods for collecting and analysing future data.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/uap/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[NASA Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science UAP</span><span class="citation-popover-snippet">NASA ScienceUAP - NASA ScienceFebruary 23, 2026...</span><span class="citation-popover-meta">Published: February 23, 2026</span></span></span>

For cases involving military and nuclear-related environments, better data also improves security analysis. A well-characterised observation can be more quickly identified as an aircraft, drone, [satellite]({{ 'satellite/' | relative_url }}), natural phenomenon, or sensor issue. When data is incomplete, however, uncertainty remains even when the event itself may eventually have a conventional explanation.

AARO’s unresolved cases therefore demonstrate a practical lesson in evidence evaluation: the hardest cases are often not those with the strangest descriptions, but those where the available measurements are too limited to decide between competing explanations. Better sensors, better recording practices, and better preservation of technical data are the main tools for turning unknown reports into identifiable events.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/uap/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[NASA Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science UAP</span><span class="citation-popover-snippet">NASA ScienceUAP - NASA ScienceFebruary 23, 2026...</span><span class="citation-popover-meta">Published: February 23, 2026</span></span></span>

      link.setAttribute('href', buildUrl(query, reference, marketId));
    });

    if (select && available.indexOf(marketId) >= 0) select.value = marketId;

    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });

      flag.className = flagClass(marketId);
    });

      label.textContent = selectedText;
    });

      label.textContent = domainLabel(marketId);
    });

      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }

      });

    }

        applyMarket(section, select.value, true);
      });
    }

    var menu = section.querySelector('[data-ebay-market-menu]');

      trigger.addEventListener('click', function (event) {
        event.stopPropagation();

        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });

        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
