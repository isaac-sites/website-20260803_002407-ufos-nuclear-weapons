## Introduction

The GoFast video is one of the most discussed UAP recordings because it appears to show a small object racing above the ocean at extraordinary speed. However, the central lesson of the case is not that the object was definitively identified, but that apparent motion in a sensor recording can differ greatly from the object’s actual movement. Analysis by the Department of Defense’s All-domain Anomaly Resolution Office (AARO) found with high confidence that the object did not demonstrate anomalous speed and that the dramatic impression of rapid movement was largely caused by viewing geometry, including motion parallax.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/UAP-Cases/Official-UAP-Imagery/4/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-title">UAP Imagery</span><span class="citation-popover-snippet">AARO UAP Imagery...</span></span></span>

The case remains important because it illustrates a recurring problem in UAP investigations: a video can be genuine, recorded by advanced military equipment, and still lack the measurements needed to prove extraordinary performance. GoFast shows why distance, perspective, [sensor limitations]({{ 'sensor-limitations/' | relative_url }}), and missing data are central when assessing claims of extreme acceleration or speed.

## The reported object and original observations

The GoFast recording was captured in January 2015 by the crew of a U.S. Navy F/A-18F fighter aircraft using a forward-looking infrared (FLIR) sensor system. The footage was later released publicly as one of the Navy UAP videos that attracted widespread attention. In the recording, the camera tracks a small object while the aircraft is moving at high speed. Audio from the cockpit captures pilots reacting with surprise as the object appears to move rapidly across the display.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/UAP-Cases/Official-UAP-Imagery/4/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-title">UAP Imagery</span><span class="citation-popover-snippet">AARO UAP Imagery...</span></span></span>

At first glance, the video seems to show an object travelling extremely quickly just above the ocean surface. That interpretation comes mainly from the relationship between the object, the moving background, and the aircraft’s own motion. Because the recording does not provide a normal visual reference such as a nearby horizon feature, scale comparison, or a complete three-dimensional view, the apparent scene can be misleading.

The key question is not whether the object moved across the camera image quickly. It did. The question is what that image movement represents in physical space. A sensor records angular movement — how much an object appears to shift within the camera’s field of view — rather than directly measuring speed unless the distance and geometry are known.

This distinction separates two different claims:

* **Observed claim:** the object appears to move rapidly across the infrared display.
* **Physical claim:** the object itself is travelling at an extraordinary speed.

The second claim requires additional information, including accurate distance, altitude, aircraft position, sensor orientation, and environmental conditions.

## Distance and perspective explanations

The main technical issue in GoFast is motion parallax, an optical effect in which an object can appear to move quickly relative to the background when viewed from a moving observer. A nearby object may seem to shift dramatically, while a distant object may appear almost stationary even when both are experiencing similar relative motion. AARO describes this effect as one reason slow-moving or stationary objects can appear to move rapidly from a fast-moving platform.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/FAQ/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-snippet">AARO FAQ...</span></span></span>

In the GoFast video, the F/A-18 itself was travelling rapidly while the infrared system tracked the object. The changing angle between the aircraft, the object, and the background created the impression of extreme speed. AARO’s reconstruction estimated that the object was not close to the ocean surface but was instead at an altitude of approximately 13,000 feet. Under that interpretation, the object’s movement was consistent with ordinary atmospheric motion rather than an object making extraordinary manoeuvres.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/Portals/136/PDFs/case_resolution_reports/AARO_GoFast_Case_Resolution_Card_Methodology_Final.pdf?ver=qXvjrruO_0MgtnTsfYnCEQ%3D%3D" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-snippet">UNCLASSIFIED...</span></span></span>

A simple analogy is watching a nearby road sign from a moving car. The sign appears to rush past extremely quickly, while distant mountains appear to move slowly. The difference is not caused by the sign travelling faster; it is caused by the observer’s movement and the relative distances involved. In aerial surveillance footage, the same principle can create dramatic impressions on a much larger scale.

The GoFast case also demonstrates why infrared footage requires careful interpretation. FLIR systems are highly capable military sensors, but they are designed for operational purposes rather than automatically providing a complete scientific measurement package. A recording may show a target, tracking information, and camera movements while still lacking enough information to independently calculate the object’s true trajectory.

## Why speed claims require better data

A major challenge in UAP cases is that speed cannot be calculated reliably from appearance alone. To determine whether an object is displaying unusual performance, investigators need several pieces of information together:


<div class="content-enhancement content-enhancement--metric" markdown="1">

* **Accurate range measurement:** The same apparent movement can represent very different speeds depending on whether an object is hundreds of metres away or several kilometres away.
* **Sensor metadata:** Exact camera settings, tracking modes, and calibration information help determine what the sensor was actually measuring.
* **Aircraft position and movement:** The observer’s own speed and direction affect the apparent motion of the target.
* **Environmental information:** Wind speed and direction can help distinguish a powered object from a balloon, debris, or other atmospheric object.

</div>

AARO’s detailed GoFast methodology report noted that its reconstruction relied on extracting information from the publicly available video because the original classified recording and associated metadata were not available for the public analysis. The office therefore calculated possible solutions rather than relying on a single perfect measurement.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/Portals/136/PDFs/case_resolution_reports/AARO_GoFast_Case_Resolution_Card_Methodology_Final.pdf?ver=qXvjrruO_0MgtnTsfYnCEQ%3D%3D" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-snippet">UNCLASSIFIED...</span></span></span>

AARO concluded that the available data did not show anomalous performance characteristics. Its assessment estimated possible object speeds that were compatible with ordinary atmospheric behaviour and found no evidence that the object was moving against the wind in the analysed scenarios.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/Portals/136/PDFs/case_resolution_reports/AARO_GoFast_Case_Resolution_Card_Methodology_Final.pdf?ver=qXvjrruO_0MgtnTsfYnCEQ%3D%3D" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-snippet">UNCLASSIFIED...</span></span></span>

The remaining uncertainty is important: explaining the apparent speed does not necessarily mean the object’s exact identity has been proven. A case can be resolved at the level of “the video does not demonstrate extraordinary speed” while still leaving open what the object itself was. This distinction is central to evaluating UAP evidence. The strongest conclusion from GoFast is not that every detail of the object is known, but that dramatic visual impressions must be separated from verified physical measurements.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/UAP-Cases/Official-UAP-Imagery/4/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-title">UAP Imagery</span><span class="citation-popover-snippet">AARO UAP Imagery...</span></span></span>

The GoFast case therefore serves as a practical example of why sensor limitations matter in UAP investigations. Advanced equipment can capture important observations, but without complete context it may show an appearance of extreme performance rather than evidence of it.

    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
